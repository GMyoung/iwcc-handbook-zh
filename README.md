# 伊利诺伊工伤手册 · 中文阅读版

以 IWCC [2024 年修订版手册](https://iwcc.illinois.gov/content/dam/soi/en/web/iwcc/documents/handbook/IWCC%20handbook%2006.06.24.pdf)为主要内容，结合用户提供的 2013 年手册目录，整理为 11 个独立章节页、94 个逐条阅读页。2013 年版独有的两个立案问题已改写为当前电子立案指引。

每条页面直接提供中文规则解释、对应人物情境、互动演示和精简出处；英文版直接呈现 2024 年手册相应答复。第 9 章收录完整法定部位表。真实判例注明当事人、争议、裁判结果并链接至伊利诺伊州法院判决；一般人物情境标注为虚构。

左侧章节进入不同的章节页，知识点进入独立的 `#/lesson/<编号>` 地址。支持搜索、顺序学习、字号调节、进度保存、手机目录和减少动态效果。

## 本地运行

```bash
npm ci
npm run dev
npm run build
```

推送 `main` 后，GitHub Actions 发布 GitHub Pages。无需 API key、后端或付费图片服务；GPT API 花费 $0。英文版在 [独立仓库](https://github.com/GMyoung/iwcc-handbook-en)。

本站是学习材料，个案结果须核对事实与现行法律。计算演示不计法定上下限。IWCC [手册发布页](https://iwcc.illinois.gov/about/handbook.html)于 2026-09-28 核对。
